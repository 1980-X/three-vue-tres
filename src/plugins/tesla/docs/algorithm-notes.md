## 数据流

```text
Geolocation.watchPosition (+ 可选 getCurrentPosition)
 → 样本时间 / 精度 / 跳变检查
 → 原生速度，缺失时用位置差与时间差估算
 → 速度与加速度平滑
 → 推断油门 / 制动 / 负载
 → 虚拟变速箱、发动机惯性、RPM、升降挡
 → 多层音频的转速、负载混合和换挡音效
 → Web Audio → 浏览器媒体输出
```

## 保留的数值行为

`motion.mjs` 保留源站 MotionEstimator。默认 smooth 模式速度时间常数 1 秒、加速度 1.2 秒；坐标精度阈值 50 米，有原生速度时容许到 100 米；最小位移 3 米；最大速度 85 m/s、最大加速度 10 m/s²；3 次连续拒绝后可重新同步。`coords.speed = 0` 是有效静止速度，不能当作“缺失”处理。设备没有速度时用 Haversine 距离除以时间差，处理漂移、静止和重启。

`powertrain.mjs` 保留 VehicleModel / PowertrainModel / DemoInput。每个音色有独立齿比、终传、轮胎周长、升降挡阈值、低负载巡航策略、急加速降挡、收油保持、换挡时间和转速跟随。巡航油门下限 0.06；减速时可能出现负负载。挡位不能用简单固定车速区间代替。

`audio.mjs` 保留合成波形、分层采样、对数转速等功率交叉混合、正负负载分层、音调变化、循环粒子交叉淡化、滤波与压缩、换挡及合成 afterfire。配置有相关 afterfire 数值；当前公开配置没有单独的 afterfire 文件列表。

12 套配置的数值字段与公开配置保持一致，仅改资源路径及展示/本地可选元信息。原始 license 等字段仍在配置中。

## 本地编排

- 控制器以 20 Hz 更新模型；Web Audio 独立调度音频，不依赖 Vue 渲染帧率发声。
- 3.5 / 8 秒 freshness 阈值来自估算器；**延迟时逐步收回模型输入、丢失时静音、无首个位置时待机**是本地页面的明确处理策略。
- 自动车机模式在 AudioContext 被挂起时也持续读取 GPS 和更新仪表，点按可恢复音频。该改动只改变音频启动生命周期，不修改 DSP 参数。
- 页面切换、隐藏、卸载会取消位置监听、定时器、按压状态、音频和屏幕常亮；异步加载及迟到的定位回调按会话隔离。
- 车机页强制 GPS 模式，继承音色、音量、强度、换挡音效及处理设置。其“静止/加速/减速/匀速”仅为 GPS 推断。
- localStorage 仅保存音色 ID、输入模式与设置；不保存或上传坐标。

## 对照方法

`tests/fixtures/upstream-trace.json` 从独立抽出的未改动源站估算器/动力总成生成。用同一段 65 秒输入轨迹对比 12 个音色，每个 33 个检查点（共 396 个）及完整换挡事件；本地核心逐项深度相等。该测试证明指定输入轨迹上的数值一致，不能代替实车误差、音质或驾驶页全行为验证。

诊断页保留 15 秒观察窗口、1.5 / 3 秒更新频率分档、至少 4 个间隔及 50 米精度判断。定位摘要不包含经纬度。提示音的“听到了”需要用户确认，程序不能以“AudioContext 正在运行”替代实际听觉结果。

# 户型设计工坊

参考 [wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d) 的二维布置、三维预览与方案管理方式，按 TvT.js 的插件目录重新实现。使用新的示例户型和参数化家具，未直接嵌入原项目的整页 HTML。

## 入口

- 设计页：`/#/plugins/floorplan3D/index`
- 独立展示页：`/#/plugins/floorplan3D/viewer`
- 预览中心注册了「户型设计工坊 · 2D / 3D」和「户型方案 · 独立展示」两个入口。设计页使用户型示意图，展示页使用真实页面录制的动态 WebP（300×186、12 帧、2.4 秒）。

设计页的「独立展示」会在新标签页打开当前方案的只读快照；展示页也支持直接导入 JSON，以及导出 JSON、当前视图 PNG 和 GLB。快照保存在同源浏览器本机，保留最近 8 份；需要跨设备交付时请导出 JSON 或 GLB。没有快照参数时，展示页读取本机上次保存的设计，首次使用则显示示例户型。展示页导入方案不覆盖设计页的自动保存。

## 功能

- SVG 二维平面：22 种家具，支持点击或拖入、移动、复制、旋转、尺寸与颜色调整。
- 5 cm 网格吸附与水平/垂直墙边吸附；按住 Alt 暂停吸附。滚轮缩放，鼠标右键/中键拖动平移，按钮恢复适应窗口。
- 两点测量、新建隔墙、编辑隔墙端点/厚度、拆墙、添加与调整门窗洞口；承重墙在界面中锁定。
- 6 种地面材料、房间面积与铺装材料费用估算，含 5% 损耗，不含人工、辅料和家具。
- 三维参数化家具、地面纹理、门窗、阴影；鸟瞰/斜视/俯视、房间定位、完整墙/剖切墙切换，三维家具拖动后同步二维方案。
- 最近 60 个方案状态的撤销/重做，每次完成操作后自动保存本机；方案 JSON 导入/导出与格式校验。
- 当前二维平面或三维视角 PNG 导出；单文件 GLB 导出。

房间地面由方案内的多边形定义，拆改墙体不自动重算房间面积；修改房间轮廓时，需要修改导出 JSON 内的 `rooms[].points` 后重新导入。家具为尺寸可调的示意模型，费用为材料估算，不能替代施工图和实际报价。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| V / M / W | 选择 / 测量 / 画墙 |
| T / F | 切换二维三维 / 适应窗口 |
| R / Shift+R | 顺时针 / 逆时针旋转 90° |
| Delete / Backspace | 删除家具或非承重墙 |
| Ctrl/⌘+D | 复制家具 |
| Ctrl/⌘+Z | 撤销 |
| Ctrl/⌘+Shift+Z / Ctrl+Y | 重做 |
| Shift | 测量、画墙时锁定水平或垂直 |
| Esc | 取消当前操作与选择 |

快捷键只在案例区域获得焦点时生效，输入框内不拦截文字编辑快捷键。

## 方案与 GLB 约定

- JSON 标识：`format: "tvt-floorplan"`、`version: 1`、`units: "m"`；墙高 2–6 m。
- 二维使用 `(x, y)`，三维对应 `(x, 0, y)`；GLB 为米制、Y 轴向上。
- `rooms`：房间 `id`、`name`、`surface`、`points`；点坐标范围为 -100–100 m，轮廓不得自交。
- `walls`：`start`、`end`、`thickness`、`bearing`、`openings`；洞口的 `offset` 为沿墙从起点到洞口中心的距离，`sill` 为底部离地高度。洞口不得越界或重叠。
- `furniture`：目录中的 `type`、唯一 `id`、`name`、中心位置 `x/y`、`width/depth/height`、角度 `rotation`、十六进制颜色 `color`。
- GLB 始终从当前方案创建完整模型，使用完整墙高与全部家具，内嵌生成的地面纹理；预览中的剖切、图层隐藏、相机、灯光和选中框不会混入交付模型。
- 保留楼板、地面、墙体、家具节点名称与必要的房间/墙体/家具元数据；GLB 用于模型交付，再编辑请保留 JSON。
- 方案导入上限 2 MB、80 个房间、300 面墙、400 件家具、每面墙 20 个洞口。

验证范围：展示页真实渲染与动态 WebP 的采集、解码和播放已检查。遵循项目规则，未运行 build/dev/preview 命令；完整编辑交互与 GLB 导出尚未验证。

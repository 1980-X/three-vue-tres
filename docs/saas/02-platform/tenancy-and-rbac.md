# 多租户与 RBAC

## 隔离模型

- **强隔离：** 所有租户业务表含 `tenant_id`；服务层强制注入，禁止客户端传任意租户覆盖（超管接口除外）。  
- 资产文件路径按租户/项目分目录，禁止直接拼未授权路径。  

## 角色

| 角色 | 含义 |
| --- | --- |
| owner | 租户拥有者；成员与危险操作 |
| admin | 管理成员与项目配置 |
| editor | 编辑展馆与资产，默认可发布 |
| viewer | 只读后台 |

平台级 **superadmin**：代建租户、禁用租户等；与租户角色分离。

## 开户

- 一期：**运营代建**（脚本或超管 API）  
- 不做自助注册商用漏斗、不做付费开户  

## 认证（需求约束）

- 支持账密登录  
- 会话凭证须避免明文落本地可读存储作为唯一方案；优先 HttpOnly Cookie 或等价安全方案（具体栈在 implementation plan 选定）  
- 登出后管理端不可继续调用需鉴权 API  

## 审计（一期最低）

- 记录：登录失败、发布、下架、成员角色变更（存谁、何时、对哪一资源）  
- 不对访客浏览做完整行为分析商业化（可后续）

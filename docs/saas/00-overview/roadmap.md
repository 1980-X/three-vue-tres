# 路线图

## 一期（当前文档包）

- 多租户控制面 + 展馆双轨（全景 / 3D）  
- 管理后台：内容闭环 + 组织角色  
- 访客：PC / 手机 Web / WebXR  
- 部署：仅 gpu001；腾讯云文档预留  

## 二期（候选）

- 微信小程序（WebView 或原生壳）  
- 腾讯云应用机 CD（`deploy/tencent` 类分支、NPM 域名、可选 COS）  
- 发布版本历史增强、回滚 UX  
- 微信内分享卡片/JS-SDK（若业务需要）  
- 场景包流水线与区域编辑器更深集成  

## 三期及以后（占位，不进一期详规）

### C1 城市数字孪生

- 复用 Tenant / Project / Publication  
- 新增城市场景类型与 GIS/城市插件包工作流  
- 行业数据接入（IoT/业务 API）另立需求  

### C2 工厂数字孪生

- 复用同一控制面  
- 工业场景、设备状态、产线漫游等能力包  

## 明确不排期（除非新开需求）

- 自助付费、套餐商城、发票  
- 将 ICEGL tvtstore 账号体系直接当作本 SaaS 租户体系

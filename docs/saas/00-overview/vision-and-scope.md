# 愿景与一期范围

## 愿景

基于本仓库 **TvT.js** 二次开发，建设多租户 **数字孪生展馆 SaaS**：租户在管理后台创建并发布线上展馆；访客通过 PC、手机 Web、VR 头显（WebXR）访问。远期覆盖城市/工厂数字孪生工作台；一期聚焦展馆产品与可部署控制面。

## 关键事实

- **TvT.js 不是现成 SaaS。** 本仓是 Web3D 框架 + 插件案例库（Apache-2.0）。无多租户计费控制台。
- ICEGL **tvtstore / 区域编辑器 / dcser** 是外部生态，不视为本产品多租户后端。
- TvT 在本产品中定位为 **3D 场景引擎与场景资产来源**；全景展馆使用独立播放运行时。

## 架构主线（已定）

**同仓 apps 分层：**

- `apps/api` — 租户、成员、项目、资产、发布、鉴权  
- `apps/admin` — 管理后台  
- `apps/viewer` — 访客端（全景 + TvT 3D/WebXR）  
- 既有 `src/plugins` 等 — 引擎/案例；被 viewer 引用，不作 SaaS 壳

## 成功标准（需求层）

1. 租户数据强隔离：A 无法读写 B 的项目/展馆/资产。  
2. 草稿不可经公开 URL 访问；发布/下架行为正确。  
3. 已发布展馆可在 PC 与手机 Web 打开；3D 馆在支持设备上可进 WebXR 或明确降级。  
4. gpu001 上可用 Compose 拉起 api/admin/viewer/db（健康检查清单见部署文档）。  
5. 文档分类齐全，可据此进入 implementation plan，而无需再澄清一期边界。

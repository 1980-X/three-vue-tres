# 术语表

| 术语 | 定义 |
| --- | --- |
| Tenant | 租户（客户组织），数据隔离根 |
| Member | 租户内用户账号 |
| Role | `owner` / `admin` / `editor` / `viewer` |
| Project | 租户内项目容器 |
| Venue | 展馆：可编辑、可发布的体验单元 |
| VenueKind | `panorama` \| `scene3d` \| `hybrid` |
| Asset | 媒资或场景包（全景图/视频、模型、TvT 场景导出等） |
| Hotspot | 热点（跳转、信息、媒体等） |
| Tour | 导览路径/镜头序列 |
| Publication | 发布快照；访客只读此快照 |
| publicId | 公开访问标识（URL 段或 token） |
| TvT Engine | 本仓 Three/Tres/插件运行时，用于 scene3d |
| Panorama Runtime | viewer 内全景播放器，非 TvT 案例预览壳 |
| Platform Superadmin | 运营代建租户的平台级角色（非租户内角色） |

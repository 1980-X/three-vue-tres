# 管理后台与访客端

## 管理后台（`apps/admin`）

### 角色可见能力

| 能力 | owner | admin | editor | viewer |
| --- | --- | --- | --- | --- |
| 项目管理 | ✓ | ✓ | 只读 | 只读 |
| 成员与角色 | ✓ | ✓ | — | — |
| 展馆/资产编辑 | ✓ | ✓ | ✓ | 只读 |
| 发布/下架 | ✓ | ✓ | ✓（可配置收紧为 admin+） | — |
| 租户开户 | 平台超管，非本表 | | | |

默认：**editor 可发布**；若客户要求收紧，用配置开关限制为 admin+（实现计划落实，需求预留）。

### 一期功能清单

1. 登录；切换当前项目  
2. 项目 CRUD  
3. 成员邀请/移除、角色变更  
4. 资产库：上传、替换、删除、列表  
5. 展馆：创建（选 kind）、编辑草稿、配置热点/导览、预览草稿  
6. 发布：生成/展示公开链接；下架  
7. 不做：计费、套餐、用量商业看板  

## 访客端（`apps/viewer`）

### 入口

- 公开 URL 形如 `/v/:publicId`（最终形态可调整，但必须是稳定、可分享的公开标识）  
- **仅**加载 `published` 快照  

### 终端

| 终端 | 一期 |
| --- | --- |
| PC Web | 必做 |
| 手机 Web（含微信内置浏览器） | 必做 |
| VR 头显 WebXR | 必做（不支持则降级桌面/触控漫游并提示） |
| 微信小程序 | 不做 |

### 运行时选择

- `panorama` → 全景 Runtime  
- `scene3d` → TvT Engine（可 WebXR）  
- `hybrid` → 默认主轨；提供切到副轨的入口  

## 发布数据流

```text
草稿编辑 → 草稿预览(需登录+权限)
       → 发布(写 Publication 快照, publicId)
       → 访客只读快照
下架 → 公开访问返回下架页或 403
```

## 错误体验（需求）

- 未登录访问管理 API → 401  
- 跨租户/无权限 → 403  
- 公开访问未发布或已下架 → 404 或统一下架页（选型在计划中固定一种）  
- 上传失败 → 可读错误信息；环境级存储硬顶可拒绝并提示（非商业套餐）

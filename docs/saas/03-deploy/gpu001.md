# gpu001 部署（一期唯一运行态）

## 目标拓扑

```text
客户端 (局域网 / Tailscale)
  → 宿主机入口端口（分配后登记 ops-hub port-map）
    → 反代 (compose 内 nginx 或独立)
      → apps/admin
      → apps/viewer
      → apps/api
      → postgres
      → （可选）redis
资产目录 bind：/mnt/storage/<product>/... 或项目 data/（禁止只写容器可写层）
```

## 仓库与 Git

- 业务真源：本仓；remote 习惯：`origin`（GitHub fork）、`joyx`（`git@joy-x:wilber/three-vue-tres.git`）、`upstream`（hawk86104，只读）  
- 密钥：`.env` / 本机密钥，**禁止**提交 Git  
- CD：可用本机 Gitea Actions（`gitea-act-runner`）；一期允许文档写「手工 `docker compose up -d`」为可接受路径  

## Compose 约定（需求）

- 项目名隔离（`-p` 或 name），**不**占用他栈端口、**不**改 NPM 上无关 host  
- 健康检查：api `/health`（或等价）、db ready、admin/viewer 静态可 200  
- 文档须给出：首次启动、迁移、备份资产目录、日志查看  

## 与现有 TvT 预览模式共存

- 保留 `yarn pre.dev` 等案例预览，供引擎开发  
- SaaS 入口走 `apps/*` 与 compose 服务，**不**要求用 preview.vue 充当多租户后台  

## 禁止写入默认 runbook 的操作

- `docker system prune`  
- 映射无关数据库端口到宿主机（除非明确需要且登记）  
- 在文档中粘贴真实密码/Token
